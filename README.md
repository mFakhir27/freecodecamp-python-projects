# freecodecamp-python-projects
# Python Learning Journey

A collection of Python mini-projects and workshops completed as part of the **freeCodeCamp Python Certification**.

## Projects

### 1. Employee Profile Generator
* **File:** `employee_profile_generator.py`
* **Description:** A Python script that formats employee details into a clean profile card and extracts department, year, initials, and ID data from an employee code.
* **Concepts Practiced:**
  * String concatenation and compound assignment (`+=`)
  * Type conversion (`str()`)
  * Formatted string literals (`f-strings`)
  * String slicing using positive and negative indexing

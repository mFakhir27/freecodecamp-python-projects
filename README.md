# freecodecamp-python-projects
# Python Learning Journey

A collection of Python mini-projects and workshops completed as part of the **freeCodeCamp Python Certification**.

## Projects

### 1. Employee Profile Generator
* **File:** `employee_profile_generator.py`
* **Description:** A Python script that formats employee details into a clean profile card and extracts department, year, initials, and ID data from an employee code.
* **Concepts Practiced:**
  * String concatenation and compound assignment (`+=`)
  * Type conversion (`str()`)
  * Formatted string literals (`f-strings`)
  * String slicing using positive and negative indexing
  
### 2. Employee Profile Validator
* **File:** `employee_profile_validator.py`
* **Description:** A Python script that cleans, formats, and validates employee profile data including names, emails, phone numbers, addresses, and employee codes.
* **Concepts Practiced:**
  * String searching and membership (`find()`, `in`)
  * Cleaning and case formatting (`strip()`, `lower()`, `upper()`, `title()`)
  * Modifying and restructuring strings (`replace()`, `split()`, `join()`)
  * Validation and counting (`startswith()`, `endswith()`, `count()`)
  * Dynamic string slicing
    
### 3. Build a Bill Splitter** | Calculates total restaurant bill with a 25% tip, splits it among friends, and rounds to 2 decimal places. | [main.py](./bill-splitter/main.py) |

* **concepts Practiced:**
- Variables and basic arithmetic operators
- Augmented assignment operators (`+=`)
- String formatting with f-strings
- Rounding floating-point numbers with `round()`
